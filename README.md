# Python Data Science Portfolio

This repository contains end-to-end data science projects built with Python.
The projects focus on data cleaning, exploratory data analysis (EDA), statistical analysis, and modeling using Python.

## 📁 Projects

### 1. Car Price Analysis (EDA & ANOVA)
- Objective: Identify key factors that influence car prices
- Methods: Data cleaning, visualization, one-way ANOVA
- Tools: pandas, numpy, matplotlib, seaborn, scipy
  

More projects will be added, including regression and machine learning models.
